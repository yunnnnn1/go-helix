编辑拓扑策略

仅作用于所选集群；未单独配置时沿用配置文件默认值。保存后经 Raft 同步到全部 Manager 并持久化，重启或 Leader 切换不丢失。

编辑接入端点

选择业务连接数据库使用的固定入口类型；故障切换时由 hook 脚本把该入口指向新主。

修改集群优先级

优先级按集群生效；P0 集群需先注册并由 P0 Manager 集群管理，切换走强一致流程。

编辑通知渠道

仅修改所选渠道；登录口令、加签密钥与 Webhook 地址留空表示保持现有值。保存后经 Raft 同步到全部 Manager 并持久化。
